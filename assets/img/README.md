## Omgeving-slider (homepage)
Deze worden in de slider getoond zodra ze bestaan. Zolang ze er niet zijn,
toont de slider automatisch een bestaande foto als fallback.

| Bestand | Slide |
|---|---|
| `omgeving-zuiderpark.jpg` | Het Zuiderpark |
| `omgeving-winkels.jpg`    | Winkels / dagelijks leven |
| `omgeving-luchtfoto.jpg`  | Luchtfoto Leyenburg (water & lanen) |
| `omgeving-strand.jpg`     | Strand & duinen |

**Aanbevolen:** liggend, minimaal 1600px breed, JPG.
